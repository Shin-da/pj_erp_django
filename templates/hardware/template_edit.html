Data notes
  • Stone prints as G-… for gold or D-… for diamond (from metal/name). Clear the prefix field — it is added automatically.
  • Selling price / × rate print as whole numbers (no commas or decimals), rounded.
  • Subcategory is what legacy tags often printed on the tail (e.g. BNG). The tail is on the front face only.
  • Supplier code uses the supplier reference code (falls back to name).
  • Colour / size / quality print blank until those columns exist on the product master.
